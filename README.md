# UNITRAMP — КП под клиента

Практикум отдела продаж на 18 ноября 2026 года.

Выберите клиента: собственник ТЦ или сетевик с тремя центрами. Оба проекта — 2000 м². После выбора показываются только слайды соответствующей ветки.

## Запуск
Откройте index.html в браузере. Дополнительные зависимости не требуются.

## Управление
- Стрелки влево/вправо или пробел — листать.
- F — полноэкранный режим.
- M — оглавление.
- «Сменить клиента» — вернуться к выбору кейса.

Есть таймер самостоятельной работы на 20 минут.

## GitHub Pages
В Settings → Pages выберите Deploy from a branch, ветку main, папку / (root).
